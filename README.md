# osa

Portfolio of Osanda Senevirathna, UI/UX and brand designer.

React, Vite, Tailwind CSS, GSAP (ScrollTrigger) and Lenis, deployed on Vercel.

## Run it

```bash
npm install
npm run dev
```

## Where things live

- `src/data.ts`: page copy, projects, expertise, experience and recognition
- `src/content.ts`: original project write-ups, contact details and social links
- `src/pages/`: Home, Work, case study and About pages
- `src/scenes/`: loader, nav, hero, intro, selected work, expertise and footer
- `public/covers/`: project cover images
